# VM Lab Snapshot v0.1

I sealed this snapshot as an executable contract and reorganization baseline, not as a completed VM product.

## Promoted

- canonical CLI;
- shared VM and guest-agent contracts;
- bind-checked plan-time port allocator;
- JSON-backed QEMU launch planner;
- install-safe default configuration;
- bounded local-payload guest bootstrap;
- truthful doctor;
- integration proof bundle.

## Preserved but unpromoted

- image manager;
- guest memory, ASPS, ACE, cache, and digital-twin lineage;
- advanced shell and native tools;
- universal and advanced file processors.

## Rejected from runtime

- mock orchestrator;
- broken settings and collaboration managers;
- synthetic benchmark;
- stale integration report;
- unsafe snapshot and false scaling claims.

## Withheld pending real metal

- persistent declare/start/ready/stop/destroy lifecycle;
- QMP identity, crash adoption, and graceful ACPI shutdown;
- interprocess registry and port ownership;
- guest-agent token provisioning and authenticated readiness.

## Promotion requirement

The next snapshot requires a real QEMU boot, QMP identity/status checks, authenticated guest readiness, command and file round-trip, graceful shutdown, crash adoption, restart reconciliation, and multiprocess ownership tests on actual virtualization hardware.
